Recommended breakout sessions

Real session titles from the Universe 2026 catalog, grouped by theme. Times/rooms appear once you build your personal schedule.
AI / Copilot configuration

Stop Prompting, Start Delegating: Configure Copilot to Own the Work

Ken Muse and Mickey Gousset, GitHub

Hands-on session layering Copilot's full stack onto a TypeScript app so you leave knowing which capability fits which task, and can delegate more, prompt less. Directly useful for complex, multi-part engineering workflows.

AI / Engineering

Inside GitHub Copilot's Coding Harness: Optimizing Across Every Model

Julia Kasper, Microsoft

How the Copilot team evaluates and optimizes its agent across OpenAI, Claude, and Gemini models, using reproducible benchmarks and LLM-graded regression testing.

Security

Open Pull Requests, Don't Merge Them: Fine-Grained Authorization for Hosted MCP Servers

Nick Taylor, Pomerium

A live demo of identity-aware, per-identity authorization in front of hosted MCP servers, so an agent can open a pull request but a human still controls the merge. Relevant to protecting proprietary process and firmware code.

Enterprise adoption

Building AI Fluency at UPS

Jared Hatfield, UPS

How UPS moved developers from Copilot awareness to real fluency at enterprise scale, and where to focus first. A useful adoption playbook for a large distributed engineering org.

DevOps workflow

Stop Waiting on Your Own Pull Requests: GitHub Stacked Pull Requests in Practice

Sameen Karim, GitHub

Builds a stack of smaller, dependent pull requests with the GitHub CLI, reviews it on github.com, and merges each as it's ready. A concrete workflow improvement for review-heavy engineering teams.

AI at scale

From Writing Code to Managing Agents: Scaling 50+ Services at GitHub

Anjuan Simmons, GitHub

How GitHub's own Lifecycle team moved from hand-coding fixes across 50+ services to an agentic pipeline using GitHub Actions and Copilot, including where automation pays off and where engineers still write code by hand.

Panel

The View from the Labs: What's Next for AI-Assisted Development

Cara Phillips, Anthropic; Rohan Varma, OpenAI; Kate Catlin, GitHub

A candid panel with the labs that power GitHub Copilot on where AI-assisted development capability is heading over the next two years.

Community vote

The Human Side of AI: How Building Community Drove 94% Copilot Adoption

Brittany Istenes, Independent

One of three sessions up for a community vote to reach the main stage: how a large financial services firm hit 94% Copilot adoption by focusing on human connection, not just better models.

Why this matters for Lam Research

Lam's roadmap runs through atomic-scale deposition and etch, on structures that keep getting smaller and more three-dimensional (think gate-all-around transistors and backside power delivery). That means Lam's engineering org lives at the intersection of real-time control software, sensor-driven process feedback loops, and a growing wall of tool-generated data that needs AI/ML to turn into yield and uptime gains.

It also means two things are non-negotiable: protecting the IP in that control software and process data (especially under export-control constraints), and scaling engineering tooling across a global R&D and manufacturing footprint as Lam invests billions in new lab capacity. The Universe 2026 catalog maps directly onto both problems, which is why this year's lineup is unusually relevant to your team.

Recommended breakout sessions

Real session titles from the Universe 2026 catalog, selected for relevance to semiconductor equipment engineering.
AI / real-time control software

Stop Prompting, Start Delegating: Configure Copilot to Own the Work

Ken Muse and Mickey Gousset, GitHub

Hands-on session configuring Copilot to own complex, multi-step engineering tasks end to end. Directly applicable to the kind of layered, real-time process-control codebases running Lam's deposition and etch tools.

AI / model reliability

Inside GitHub Copilot's Coding Harness: Optimizing Across Every Model

Julia Kasper, Microsoft

How Copilot is evaluated and optimized across OpenAI, Claude, and Gemini using reproducible benchmarks and regression testing. A useful reference for teams validating AI/ML models against sensor and yield data.

Security / export-controlled IP

Open Pull Requests, Don't Merge Them: Fine-Grained Authorization for Hosted MCP Servers

Nick Taylor, Pomerium

A live demo of identity-aware, per-identity authorization in front of hosted MCP servers, so an agent can draft changes but a human still controls the merge. Directly relevant to guarding proprietary process recipes, firmware, and export-controlled code as agentic workflows expand.

Enterprise adoption at scale

Building AI Fluency at UPS

Jared Hatfield, UPS

How a large, operationally complex enterprise moved developers from Copilot awareness to real fluency, and where to focus first. A useful adoption model as Lam scales engineering tooling across a growing global R&D and fab network.

Engineering workflow

Stop Waiting on Your Own Pull Requests: GitHub Stacked Pull Requests in Practice

Sameen Karim, GitHub

Splits large changes into smaller, dependent pull requests that move through review efficiently. Useful for teams making incremental changes to safety-critical, long-lived equipment control code.

AI operations at scale

From Writing Code to Managing Agents: Scaling 50+ Services at GitHub

Anjuan Simmons, GitHub

How GitHub's own team moved from manual fixes across 50+ services to an agentic pipeline for classification, research, and draft fixes. A concrete pattern for scaling engineering support across a large installed base of tools.

Panel: where AI is heading

The View from the Labs: What's Next for AI-Assisted Development

Cara Phillips, Anthropic; Rohan Varma, OpenAI; Kate Catlin, GitHub

A candid panel with the labs behind GitHub Copilot on where AI-assisted development capability is heading over the next two years, useful context for Lam's own AI/ML and digital-twin roadmap.
